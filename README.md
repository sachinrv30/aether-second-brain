# 🌌 What is Aether?

**Aether** is a local-first **Cognitive Second Brain Agent** designed to reduce information fragmentation and cognitive overload.

Instead of keeping notes, tasks, goals, decisions, habits, schedules, and ideas in disconnected places, Aether brings them together into a unified personal memory layer.

It combines:

```text
                 🧠 AETHER COGNITIVE CORE
                          │
        ┌─────────────────┼─────────────────┐
        │                 │                 │
        ▼                 ▼                 ▼
    CAPTURE            CONNECT           REMEMBER
        │                 │                 │
 Notes / Tasks       Knowledge Graph     SQLite Memory
 Habits / Goals      Relationships       Persistent Data
 Decisions           Context             History
        │                 │                 │
        └─────────────────┼─────────────────┘
                          │
                          ▼
                    ⚡ REASONING
                          │
                          ▼
                    🤖 AI AGENT
                          │
                          ▼
                    🎯 ACTION / INSIGHT
```

### Aether's core philosophy

> **Your information should not merely be stored. It should be connected, understood, and useful.**

# 🛡️ Security Architecture

Security and local privacy are core design principles.

## 🔐 Principle of Least Privilege

Aether is designed to minimize unnecessary access to user data and system resources.

---

## 🧱 XSS-Safe DOM Handling

Dynamic frontend content avoids unsafe HTML injection techniques.

Instead of:

```javascript
element.innerHTML = userInput;
```

Aether uses explicit DOM construction and safe text insertion.

```javascript
const element = document.createElement("div");
element.textContent = userInput;
```

This reduces exposure to common DOM-based injection patterns.

---

## 🗄️ Parameterized SQL

Database operations use parameterized queries.

```python
cursor.execute(
    "SELECT * FROM memories WHERE title = ?",
    (title,)
)
```

This prevents user-controlled values from being interpreted as SQL syntax.

---

## 🔒 Localhost Confinement

The local server is designed to bind to:

```text
127.0.0.1:8000
```

rather than exposing the service broadly through:

```text
0.0.0.0
```

This helps keep the development environment restricted to the local machine.

---

## 🔑 Temporary API Credentials

API keys can be maintained in browser `sessionStorage` for the active session rather than being permanently written to the project database.

> Never commit API keys, tokens, passwords, or other secrets to GitHub.

# 🏗️ Engineering Principles

Aether is built around several principles:

### 🧠 Local First

Personal information should remain under the user's control whenever possible.

### 🔗 Context Over Fragments

Information becomes more useful when relationships between pieces of information are preserved.

### ⚡ Minimal Infrastructure

A powerful prototype does not necessarily require a complex infrastructure stack.

### 🔐 Security by Design

Security should be considered from the beginning rather than added afterward.

### 🤖 Human + AI

Aether is designed to augment human thinking rather than replace human decision-making.
